# SOS — octanol stimulus response time

Avoidance response time to 33% 1-octanol across all figure genotypes, plus
speed–response correlation with locomotion subproject data.

Per-figure SOS statistics (bar plots, ECDF, pairwise brackets) are generated by
ODLabPlotTools (R package); the scripts here handle the combined cross-dataset analysis.

## Quick start — reproduce figures from cached data

No NAS access required.

```bash
cd sos

# Supplemental figure: condition comparisons (uses cached parquet)
python sos_condition_plots.py

# Speed–SOS correlation (requires locomotion/data/ to exist)
python sos_analysis.py
```

`sos_analysis.py` reads `postural_comparison_stats.csv` and `recording_data.parquet`
from `--locomotion-dir` (default: `../locomotion/data`). Run the locomotion pipeline first,
or point `--locomotion-dir` at the correct directory.

## Rescan from raw SOS data (NAS required)

```bash
python sos_analysis.py --data-dir /path/to/raw_figure_data --out-dir data/ --refresh
python sos_condition_plots.py --data-dir /path/to/SOS --out-dir data/
python sos_figure_plots.py --data-dir /path/to/raw_figure_data --out-dir data/figures/
python sos_epistasis_plots.py --data-dir /path/to/raw_figure_data --out-dir data/figures/
```

Note: `--data-dir` points to the directory containing ODLabPlotTools-formatted SOS CSV files.
`sos_epistasis_plots.py` defaults to a local NAS path; override with `--data-dir` as needed.

## Scripts

| Script | Inputs | Outputs |
|--------|--------|---------|
| `sos_analysis.py` | `data/*.parquet` (or `--data-dir`); `--locomotion-dir` for speed data | `data/speed_sos_correlation.pdf/.png`, `data/supplemental_sos_*.pdf/.png`, `data/sos_stats.csv`, `data/speed_sos_summary.csv` |
| `sos_condition_plots.py` | `data/sos_condition_animal_data.parquet` (or `--data-dir`) | `data/sos_condition_plots.pdf/.png` |
| `sos_figure_plots.py` | `--data-dir` (NAS; required) | `data/figures/*_SOSdata.pdf/.png` |
| `sos_epistasis_plots.py` | `--data-dir` (NAS) | `data/figures/1e_Epistasis_SOSdata_updated.pdf/.png` |
| `sos_style.py` | — | Shared style constants; imported by the other SOS scripts |

## Files

| File | Description |
|------|-------------|
| `data/sos_animal_data.parquet` | Per-animal SOS response times (all genotypes) |
| `data/sos_recording_data.parquet` | Per-recording SOS summary |
| `data/sos_condition_animal_data.parquet` | Per-animal data for 4-condition supplemental |
| `data/sos_stats.csv` | LMM genotype estimates |
| `data/sos_condition_lmm_stats.csv` | LMM estimates for condition comparisons |
| `data/speed_sos_summary.csv` | Per-genotype speed vs SOS table |
| `data/speed_sos_correlation.pdf/.png` | Speed–response correlation figure |
| `data/sos_condition_plots.pdf/.png` | 4-condition supplemental figure |
| `data/supplemental_sos_*.pdf/.png` | Supplemental SOS figures |
| `data/figures/` | Per-figure SOS bar + ECDF plots (from ODLabPlotTools CSVs) |
| `methods_sos_conditions.txt` | Methods text for condition comparisons figure |
