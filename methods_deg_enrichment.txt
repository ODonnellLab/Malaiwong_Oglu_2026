To assess whether genes differentially expressed in cest-2.1 mutants (DEGs) are enriched for CAN neuron-expressed and CAN-specific genes, we performed a hypergeometric enrichment test across two single-cell transcriptomic atlases: the Taylor et al. adult and L4 C. elegans neuron atlases, and the Ghaddar et al. (2023) adult C. elegans whole-organism atlas.

For each atlas, the background universe (N) comprised all genes with at least one non-missing expression measurement. For each combination of a minimum CAN expression threshold (tpm_min ∈ {1, 10, 25} TPM) and a CAN-specificity threshold (pct_max ∈ {1%, 5%, 10%, 20%, 33%, 50%}), we defined the gene pool K as genes satisfying both CAN_TPM ≥ tpm_min and CAN_TPM / gene_max ≥ pct_max, where gene_max is the maximum TPM observed for that gene across all measured cell types. The cest-2.1 DEG list (n = 26 L4 DEGs or n = 31 adult DEGs from Taylor et al., derived from Taylor_L4_GenesExpressing-BATCH-thrs2_DEGfiltered.csv and Taylor_Adult_GenesExpressing-BATCH-thrs2_DEGfiltered.csv) was intersected with the atlas universe; k denotes the number of DEGs satisfying both threshold conditions. Enrichment was calculated as (k/n) / (K/N). Statistical significance was assessed using a one-tailed hypergeometric test (upper tail, testing whether k exceeds expectation under random sampling). To control the family-wise false discovery rate, p-values were corrected using the Benjamini-Hochberg (BH) procedure applied within each panel, where a panel is defined as one dataset × one tpm_min combination (approximately 78–114 tests per panel, covering all available cat-1+ neurons × 6 pct_max thresholds). Filled markers in the figure indicate q < 0.05 after BH correction. The tpm_min parameter defines cumulative minimum thresholds (not exclusive expression bins): genes qualifying at tpm_min = 25 TPM are a strict subset of those qualifying at tpm_min = 10 TPM.

The same test was applied to all other cat-1-expressing neurons (ADE, ADF, AVM, CEP, HSN, NSM, PDE, RIC, RIH, RIM, RIR, ASI, VC_4_5) to assess specificity of any enrichment to CAN.

For the Ghaddar atlas, which covers 180 cell types including non-neuronal tissues (intestine, body wall muscle, hypodermis, gonad, pharynx), we restricted the cell type set to 104 types with names overlapping the Taylor neuron atlases: 88 exact name matches plus 16 merged Ghaddar cell types (CEP_ADE_PDE, DA_VA, DB_VB, VD_DD, PHA_PHB, PLM_ALM, PVD_FLP, URX_AQR_PQR, SDQ, AWC, ASE, IL1, IL2, RMD, RME, PLN) whose constituent neurons are present in Taylor. This restriction ensures that the gene_max denominator reflects neuronal expression rather than non-neuronal tissues, making CAN/gene_max ratios comparable across atlases. Ghaddar gene identifiers use the standard 8-digit WormBase format (e.g. WBGene00021160); Taylor identifiers carry a trailing version digit (e.g. WBGene000211602) that was stripped before cross-atlas matching. Gene name cross-referencing confirmed that apparent name discrepancies (e.g. scb-1 in Taylor mapping to H19N07.3 in Ghaddar) reflect WormBase annotation version differences rather than incorrect gene assignments, as these names are aliases for the same locus. One gene in the adult DEG list, Y17D7C.3 (WBGene000453662), is annotated as a pseudogene and was excluded from all analyses; it is absent from the Ghaddar atlas. The final adult DEG count is 40; the L4 DEG count is 26.

All analyses were performed in Python using pandas, numpy, and scipy.stats.hypergeom. Full numerical results are provided in data/deg_enrichment_can_statistics.csv (CAN only) and data/deg_enrichment_all_neurons_statistics.csv (all cat-1+ neurons).
