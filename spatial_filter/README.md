# Spatial filter — neurite–intestine proximity

Tests which of the 14 cat-1⁺ neuron types have neurite processes anatomically
adjacent to the intestine (the site of octopamine glucoside production).
Uses the Virtual Worm Blender morphology in Blender-native coordinates (114.8 µm/unit).

This is step 2 of the CAN identification argument in the rebuttal.

## Quick start — reproduce figures from cached data

No Blender required. Blender-derived CSV files are cached in `data/`.

```bash
cd spatial_filter

# Proximity distribution figure (blend_intestine_proximity.pdf)
python blend_intestine_proximity.py

# AP-axis profiles + neuron extent figure (ap_axis_proximity.pdf, neuron_y_distribution.pdf)
python blend_ap_axis_figure.py

# 3D render (can_intestine_render.pdf)
python blend_render.py
```

## Full pipeline — from Blender source

Requires `Virtual_Worm_February_2012.blend` (not in repo; large binary).

```bash
# Step 1: extract world-space vertices (Blender headless, run once)
/Applications/Blender.app/Contents/MacOS/blender \
    --background Virtual_Worm_February_2012.blend \
    --python extract_world_verts.py

# Step 2: compute nearest-neighbour distances to intestine
python blend_intestine_proximity.py

# Step 3: generate all figures (any order)
python blend_ap_axis_figure.py
python blend_render.py
python nml_morphology_figure.py  # see note below
```

## Key results (10 µm threshold)

| Neuron | d_min (µm) | Contact span (µm) |
|--------|-----------|-------------------|
| PDEL/PDER | 0.26 | 696 |
| CANL | 0.48 | 426 |
| CANR | 2.51 | 705 |
| HSN | 0.02 | 336 |
| AVM | 0.08 | 201 |
| VC4/5 | 3.9 | ~12 |
| ADE | 8.8 | ~1 |
| RIC–CEP | 30–47 | 0 |

Contact span is the primary metric. CAN and PDE clearly pass the 10 µm spatial filter;
head ganglia neurons (RIC, RIM, RIH, RIR, ADF, ASI, NSM, CEP) have zero contact.
